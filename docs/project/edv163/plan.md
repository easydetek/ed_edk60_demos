# 项目计划 — EDK60 × EDV163 水位监测 Demo

> 2026-10-22 ｜ 项目经理 ｜ 参照 `docs/project/edv11p/` 全套流程，按已验证流水线快速复制

## 一、目标与范围

| 项 | 内容 |
|---|---|
| 目标 | EDK60 把 **EDV163** 的串口数据（**256000**）纯字节透传到原生 USB；网页端显示**当前水位（cm/m）+ 到水面距离 + 水位曲线/水位柱** |
| 水位口径 | `水位 = 挂高 − target_distance`（两者单位 mm）；本次挂高默认 **2000 mm**、量程 0~2 m |
| 已定决策 | DEC-163-01 二进制固件（ASCII 版无距离数据，不可用）｜DEC-163-02 吊装、量程 ~0–2 m｜DEC-163-03 交付范围与 EDV11P 一致（固件 + 网页 + 教程 + 案例 + 发布）｜DEC-163-04 硬件在手，可上板 |
| 不做 | 不改硬件、不做云端/App、不做 ASCII 版、不做多罐组网 |

## 二、与 EDV11P 方案的实质差异（贯穿全流程）

| 维度 | EDV11P（人数统计） | EDV163（水位） |
|---|---|---|
| 波特率 | 921600 | **256000** |
| 帧尾 | 无 | **固定 0x0A** |
| 转义 | 无 | **有**：正文 `0x0A→09 01`、`0x09→09 00`（帧尾不转义） |
| 上报载荷 | `0x70`：zone + 目标 x/y/z | `0x81`：`count(1B) + count × **7B**`（channel/delay_presence/target_state/motion_direction 各 1B + `target_distance` 2B 大端 mm + `target_angle` 1B int8）；`tlv_len = 1 + 7×count` |
| 业务换算 | 无（直接展示坐标） | **水位 = 挂高 − 距离**（需下发 `0x25` 挂高） |
| 安装 | 侧装 60° | 吊装向下 |

## 五、验收判据（沿用 EDV11P 口径）

1. 30 分钟采集：坏帧率 < 0.1%、帧完整率 ≥ 99.9%（P4 口径）、未归属字节率 = 0、转义错误 = 0
2. 水位换算正确：卷尺实测距离与页面显示**同量级一致**（EDV163 距离分辨率约 **8 cm**，绝对偏差按 **≤ 1 个分辨率单元（≈80 mm）** 判；更看重**重复性与相对变化**）
3. 网页端可出水位曲线；默认只读（未点击时 SET 帧数 = 0）
4. 18/18 构建回归通过
5. 文档三件套 + 线上发布可用
