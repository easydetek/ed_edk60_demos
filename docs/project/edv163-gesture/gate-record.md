## 五、对外口径红线

**可以写**（v1.0.0 起）：文本行协议、115200、**实测 24.3~26.5 行/秒**、action 编码表与轴映射、点云混流与跳过规则、设备只读、网页自测 113/113、**已上板验证**；同时必须写明「`0x4544` 帧与 `±3` 尚未观察到」。

**不得写**：任何行率/坏行率/识别准确率/时延的实测数字；「方向已校准」；「支持自定义手势」；「点云可视化」。

## 六、经验沉淀（三条）

1. **没有协议文档时，"上位机源码"就是协议文档**——但必须逐条标行号，否则后续无法复核；厂商 README 与源码冲突时以源码为准（本次行号相差 19 行，来自解压副本与仓库版本差异）。
2. **文本协议比二进制协议脆弱得多**：没有长度、没有校验，任何固件日志都会变成"坏行"，且现场只表现为"功能偶尔不生效"。因此「桥必须零日志」在本 demo 是**功能正确性要求**，不是洁癖。
3. **桥上永远不要"顺手过滤"任何字节模式**（例如把 `0x4544` 点云帧剔掉）：载荷里会出现同样字节序列，过滤等于删真数据。桥的铁律是只改变字节到达的**时刻**，不改变字节本身。

## 七、上板实测结论（2026-10-23 补记）

| 项 | 实测值 | 判定 |

| 模组自报 | `EasyDetek` + `EDV163_VB_ID0xFFFF_V101`（**设备 ID 0xFFFF 未写**，版本 V101） | 记录 |

### 7.2 实测暴露的真实缺陷（已修）

| 缺陷 | 根因 | 处置 |
|---|---|---|
| 开机 `I (115) esp_image: …` 混进 USB 流 | **bootloader 阶段日志不受 `CONFIG_LOG_DEFAULT_LEVEL` 管** | defaults 增加 `CONFIG_BOOTLOADER_LOG_LEVEL_NONE=y`，重烧后复测：该行消失 |
| 工具 P1 判据全错 | 按厂商 README 假设 5 行/秒 | 改为 **24.3 ±20%**（实测） |
| 工具 P7 误报 | 坐标护栏 ±1.00 m 过紧 | 放宽到 **±1.50 m** |

### 7.4 本期新增功能（已随版本发布）

**挥手方向动画 + 动画锁定期**：左挥→掌从左到右、右挥→右到左、上挥→下到上、下挥→上到下；**2.5 s**（含 300 ms 淡出）；动画期间**只冻结动作展示**，解析/行率/坐标/日志/直方图照常；被忽略动作计「动画期忽略 N」；同一次检测（相邻行 ≤300 ms 同值）不重复播放；`prefers-reduced-motion` 退化为静态 + 800 ms 淡入淡出。网页自测 **98/98**。
