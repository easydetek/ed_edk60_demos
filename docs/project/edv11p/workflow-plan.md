# 开发计划 — EDK60 × EDV11P 斜装人数统计/轨迹 Demo

> 版本 v1.0 ｜ 2026-10-21 ｜ 项目经理制定 ｜ 当前阶段：**P0 侦察与方案冻结**

## 一、阶段模型（四段 + 三道 Gate）

| 阶段 | 目标 | 出口条件（Gate） |
|---|---|---|
| **P0 侦察与方案** | 摸清协议/接线/固件版本，冻结桥接方案 | Gate-1 方案冻结：方案文档 9 章齐、推荐方案唯一、控制台洁净首选方案明确 |
| **P1 固件实现与构建** | 新增 `radar_bridge_edv11p` demo，构建与合并固件就绪 | Gate-2 固件可用：17/17 构建 0 error、merge-bin 产物存在、体积记录 |
| **P2 上板实测与双端对齐** | 实测轨迹与人数；网页版与桌面端一致 | Gate-2 补充：30 分钟帧完整率 ≥99.9%、轨迹正确、双端一致 |
| **P3 文档与发布包** | Recipe、案例、烧录页、release 包 | Gate-3 发布就绪：教程自检通过、release 4 件套齐 |
| **P4 文档站上线** | 文档站页面 + 静态资源 + 构建验证 | Gate-3 补充：本地 build 通过、线上 URL 可访问、用户网页烧录通过 |

> 严格的串行点只有三个：**方案冻结 → 固件实现**、**固件构建 → 上板实测**、**实测通过 → 对外发布**。其余全部并行。

## 七、汇报节奏

- 每批次完成 → 更新本计划「状态」列 + `dispatch-log.md`。
- 每 Gate → 产出 `gate-records/` 记录 + 一页状态简报（进度/风险/决策需求）。
- 出现阻塞（缺硬件/版本不符/超范围）→ 立即升级用户，不自行改范围。
