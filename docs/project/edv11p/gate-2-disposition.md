## 三、本轮新增的两条实测事实

1. **背压计数器全 0**（有真实流量、60 s、12 次采样）。
2. **模组掉电重启后不会自动上报**：`GET` 有应答但无 `0x70` 帧；发一次 `SET 0x05=1` 立即恢复。
   → 已写入 recipe 故障排查；对「网页版默认只读」是必须提示的操作前提。
