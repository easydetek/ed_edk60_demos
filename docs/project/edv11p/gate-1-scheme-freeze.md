## 三、评审必答问题（评审官逐条给结论）

1. 桥接是否**真的不需要**任何固件侧 EDV11P 协议交互？依据是什么（上位机行为证据）？
2. 控制台洁净方案是否**同时**满足：能启动（不触发 USJ 时钟关闭）、USB 流里零非协议字节、还能保留排障手段？怎么验证？
3. 921600 连续流下，USB 缓冲与任务结构是否够用？丢字节的检测手段是什么？
4. 模组固件版本的结论是**证据支持**还是**猜测**？若为猜测，上板第一步怎么证伪？
5. 网页版与桌面端的坐标口径是否会不一致（尤其 z 的语义、y 的正方向）？如何比对？
6. 斜装 60° 是机械参数还是软件参数？文档与代码是否把这个边界守住了？
