## 三、放行结论

**GO（发布关闭）** — 线上烧录页、在线演示、教程、案例四个入口全部可用；固件哈希可核；回归与不变量（单文件、零外链、默认只读）均通过。

对外口径约束（继续有效）：
- 可以说：30 分钟、本机 USB-C 直连、统计窗口内**无坏帧无重同步**，帧完整率 100%（P4 口径）。
- 不可以说：「绝不丢帧」「轨迹与实际走位一致」「6 个 ID = 6 个人」「无人时人数归零」「已完成绝对高度标定」。
