## 四、C-1 型号判定卡

| 项 | 内容 |
|---|---|
| 现状 | **未定**。用户口头称 -02（人数统计/轨迹跟踪）；硬件工程师解包本地 6 个 hex 全为 -03 跌倒版（含 `Fallen`/`Standup Judge`，版本串 `V123SX1`/`V121SX1`，无 -02 标识）——两者不可互相推翻，只能上板定性 |
| 判定动作 | 上板第 1 步：发 `GET 0x02`（帧 `45 44 00 0B 00 01 A0 02 00 00 37`），**保存原始回读十六进制**，记录：协议版本、厂商 ID、设备 ID、固件版本、软件 ID |
| 判据 | 能稳定输出 `op=0xA3 / type=0x70` 目标上报 → -02 行为成立；只有 `0xA9 ACK`/心跳、无 `0x70` → 型号或固件分支不符 |
| 分支处置 | ① 回读为 -02 且出 0x70 → 按计划继续；② 回读为 -03/无 0x70 → 向雷达固件负责人索取 -02 固件或模组；③ 短期无法获得 → 由用户决定是否改做 `0x73` 目标坐标过渡 demo（**属于范围变更，须用户拍板**） |
| 阻断规则 | **若上板确认无 0x70 → Gate-2 直接 NO-GO**（G2「轨迹正确」不可达） |
