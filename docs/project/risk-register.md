## 二、红色风险（需重点跟踪）

### R-06 — IDF v6.1 API 差异（风险值 6）

**具体表现**：LEDC 的 `ledc_timer_config_t` 字段变化、`esp_sleep.h` 中 `ESP_EXT1_WAKEUP_ALL_LOW` 在 C6 上被弃用、NimBLE 初始化函数随版本改名、Kconfig 符号改名（如 `ESP_CONSOLE_SECONDARY_USB_SERIAL_JTAG`）。

**已采取措施**：
1. 全部 API 逐个从 `C:\esp\v6.1\esp-idf` 的头文件核对（不依赖记忆或网络资料）；
2. 关键结论写入代码注释（例如 `esp_sleep.h` 中「ESP32-C6: 0-7」的 EXT1 引脚范围）；
3. 15 个 demo 全部实际编译验证；
4. `components/edk60_app/CMakeLists.txt` 顶部记录了「组件早期展开读不到 `CONFIG_*`」这一 6.1 特有行为。

**残余风险**：运行时行为（非编译期）仍需上板验证。
