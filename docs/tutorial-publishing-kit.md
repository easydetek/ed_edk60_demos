【用 ESP32-C6 + 毫米波雷达做呼吸心率监测】

一块 C6 开发板 + 一颗 EDV151 雷达，不用任何转串口芯片、不用装驱动，
心率 75bpm / 呼吸率 21bpm 直接进 PC。

踩了 10 个坑才打通，最坑的一个：
雷达能检测到人，但心率呼吸永远是 0 ——
原因是出厂增益太大，静息体动 20~60 超过算法阈值 5，
把 set_gain 调到 0.5 立刻出数。
