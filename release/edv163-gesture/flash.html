烧完之后

  2. 看板子上的 丝印 RADAR 的红灯：亮了 = 雷达已上电，正常
  3. 打开演示页 gesture.html（同一目录，也可以直接点这个链接）
  4. 在演示页里点 「连接串口」，在弹窗里选那个 USB 串行设备； 串口参数固定 115200 8N1 无流控（页面已默认选中 115200）， 不要改成 256000 或 921600

演示页是「全链路只读」的：设备端没有命令接口，网页端也不实现任何写入—— 它只做「打开串口 → 读字节 → 解析 → 显示」，不会向板子或模组下发任何数据。

这套固件做什么

它是一根透明的桥：EDK60 板上的 ESP32-C6 把 EDV163 雷达串口上的字节 原样转发到板子的原生 USB（CDC，免驱），固件本身不做任何协议解析。 雷达输出的每一行文本、每一个点云帧都完整送到上位机，怎么解、怎么显示， 全部在上位机（网页或你的程序）里完成——雷达固件升级、协议字段调整都不需要重新烧板子。

串口里是两种内容混流：一是文本行（约每 200 ms 一行），二是以 0x4544 开头的二进制点云帧。解析时必须把二进制帧整帧跳过 （长度域 11~4096 字节，校验 = 前 n−1 字节求和 & 0xFF）， 只按行解析文本，否则二进制字节会被误当成文本。

常见问题

1. 烧好了，我用串口助手打开，看到的是成行的文本（GESTURE: target=1 x=…）？
这是正常的，这一版就是文本行协议，不是二进制协议。和 EDV151 / EDV11P / EDV163 水位 那几套 demo 不同，挥手识别固件直接把结果打成可读文本行（约 200 ms 一行）， 中间还会夹杂以 0x4544 开头的二进制点云帧——串口助手里那几段乱码就是点云帧，忽略即可。
→ 想看整理后的挥手方向与距离，请用演示页 gesture.html
→ 自己写程序对接时：端口参数 115200 8N1，按行读，遇到 0x4544 整帧跳过
2. 模组插在 H4 上行不行？
不行。H3 与 H4 的信号集合相同但顺序相反：H4 上模组的 T（数据）与 电源使能落在同一网络，插 H4 会造成电源与数据互相干扰——典型现象是红灯忽明忽暗、 串口要么没数据要么全是坏字节。
→ 断电后把模组移到 H3，插紧，再上电
3. 网页连不上串口 / 点了没反应 / 根本没有按钮？
→ 浏览器不对：只有电脑版 Chrome / Edge 支持 Web Serial；Firefox、Safari、 手机浏览器、微信内置浏览器都不支持
→ 页面不是安全上下文：Web Serial 只在 https:// 或 http://localhost 下可用。 用本站 https 页面访问即正常；直接双击打开本地 file:// 文件可能失败， 本地测试请在该目录起一个静态服务（例如 py -3 -m http.server 8771） 再访问 http://localhost:8771/gesture.html
→ 串口被占用：关掉串口助手、Arduino IDE、其它浏览器标签页后重试
→ 还不行：换一根能传数据的 USB 线（很多充电线只有电、没有数据），优先插机箱后面的 USB 口
4. 波特率必须 115200 吗？能不能用 256000 / 921600？
必须 115200。挥手识别这一版雷达固件的串口固定 115200 8N1 无流控， 和 EDV163 水位那套的 256000、EDV151 / EDV11P 的 921600 都不是一个档位。 波特率填错的表现是：串口能打开、但看不到完整的 GESTURE: 行， 行率要么是 0、要么乱跳，日志里全是截断的残行。
→ 演示页已默认选中 115200，正常不需要手动改；自己写程序对接时务必对齐这一档
5. 页面一直显示 target=0 / 位置不动，是不是坏了？
不一定坏了。target=0 表示位置尚未就绪——雷达还没凑满位置窗口 （10 帧）或当前没有稳定目标，此时 x / y / z 可能还在跳或停在旧值。 挥手动作本身仍可能被识别（action 有值）。
→ 让手在雷达前 0.2~0.8 m 内停留一两秒，再做挥手动作；确认模组跑的确实是 163_action_20260901；确认行率约 5 行/秒
另注：演示页只显示 ±2（上下左右四向）与 0（无挥）；±3（靠近 / 远离）不显示为挥手方向， 只做计数参考。
6. 我往右挥，页面显示「右挥」，但雷达装在别的角度…… 挥手方向反了怎么办？
不要在网页端改映射。方向的正负是固件 / 协议层（模组里的 163_action_20260901）定义的，与模组安装朝向强相关。网页端只是照实显示， 改网页映射会让日志、文档、你自己的程序三边口径不一致。
→ 正确做法：先确认模组安装方向与说明书一致；方向确实不符时， 反馈给 support@easydetek.com 并说明安装朝向与实测方向，由固件侧评估
→ 另外：本页与演示页都没有任何写入功能——设备端没有命令接口， 网页端不发任何下行数据，所以也无法「在网页里配置雷达」
