EDK60 人数统计雷达固件 · 一键烧录

EDK60_VA V1.0（ESP32-C6）+ EDV11P 人数统计/轨迹雷达的桥接固件。 不需要安装任何软件。用 Chrome 或 Edge 浏览器打开本页，插上 USB 线，点按钮即可。

开始前，确认三件事

✅检查项怎么确认
1雷达模组已插在板子的 H3 排针上模组插紧，不要插在 H4（H4 顺序相反，会电源/数据互扰）
2USB-C 线已连到电脑板上有绿灯亮，电脑设备列表里能看到串口
3用的是 Chrome / EdgeFirefox、Safari 不支持 Web Serial，会看不到烧录按钮

烧录（三步）

  1. 点下面的按钮，浏览器会弹出一个设备列表
  2. 在列表里选带 USB / JTAG / COM 字样的那一项，点「连接」
  3. 点 安装 / Install，等进度条走完（约 10~20 秒），看到「完成」就好了
当前浏览器不支持。请改用电脑上的 Chrome 或 Edge 打开本页。 本页需要用 https:// 或 localhost 打开才能使用串口功能。

如果按钮点了没反应，见下面「常见问题」第 3 条。

本次写入的内容：合并固件 edk60_edv11p_track.bin， 244,192 字节，烧录偏移 0x0，目标芯片 ESP32-C6，版本 1.0.0。 烧录器会自动整片擦除后写入（一次成型，不需要分别烧 bootloader / 分区表 / app）。

烧完之后

  1. 拔掉 USB 线，等 2 秒，再插回去（让板子重新启动）
  2. 看板子上的 丝印 RADAR 的红灯：亮了 = 雷达已上电，正常
  3. 打开演示页 track.html（同一目录，也可以直接点这个链接）
  4. 在演示页里点 「连接串口」，在弹窗里选那个 USB 串行设备； 串口参数固定 921600 8N1 无流控，页面已设好，无需手填
  5. 数据会自己开始滚动，右侧状态条能看到帧率、坏帧数、当前目标数
  6. （可选）只有需要改写雷达配置时，才点页面下方 「下发配置…（需确认）」， 并在确认框里点确定；取消则一条写指令都不会发出
演示页是「默认只读」的：连上之后只发查询指令，不改写模组配置、不写浏览器本地存储。
首次连接时如果数值全是「未回读」，等 1~2 秒即可——那是页面在逐条查询设备当前参数。

这套固件做什么

它是一根透明的桥：EDK60 板上的 ESP32-C6 把 EDV11P 雷达串口上的字节 原样转发到板子的原生 USB（CDC，免驱），固件本身不做任何协议解析。 也就是说雷达上报的每一帧都完整送到上位机，帧结构怎么理解、人数怎么统计、轨迹怎么画， 全部在上位机（网页或你的程序）里完成。好处是雷达固件升级、协议字段调整都不需要重新烧板子。

常见问题

1. 烧好了，但我用串口助手打开只看到一堆乱码 / 乱字符？
这是正常的，不是坏了。本固件转发的是雷达的二进制协议帧（以 0x5A 开头的定长帧， 中间含不可打印字节），不是文本。串口助手默认按文本显示，自然就是乱码。
→ 想看有意义的内容，请用演示页 track.html（它按协议解析并画轨迹）
→ 想在串口助手里看，切到 Hex / 十六进制显示，端口参数必须 921600 8N1
2. 模组插在 H4 上行不行？
不行。H3 与 H4 的信号集合相同但顺序相反：H4 上模组的 T（数据）与 电源使能落在同一网络，插 H4 会造成电源与数据互相干扰——典型现象是红灯忽明忽暗、 串口要么没数据要么全坏帧。
→ 断电后把模组移到 H3，插紧，再上电
3. 网页里点「连接串口 / 开始烧录」没反应，或者根本没有按钮？
→ 浏览器不对：只有电脑版 Chrome / Edge 支持 Web Serial；Firefox、Safari、 手机浏览器、微信内置浏览器都不支持
→ 页面不是安全上下文：Web Serial 只在 https:// 或 http://localhost 下可用。 直接双击打开本地 file:// 文件会失败；本地测试请在该目录起一个静态服务 （例如 py -3 -m http.server 8771）再访问 http://localhost:8771/flash.html
→ 串口被占用：关掉串口助手、Arduino IDE、其它浏览器标签页后重试
→ 还不行：换一根能传数据的 USB 线（很多充电线只有电、没有数据），优先插机箱后面的 USB 口
4. 供电有要求吗？
建议用 DC-005 圆孔电源座 + 5V / ≥2A 适配器供电，USB 只负责数据。
理由：雷达模组启动瞬间峰值电流 < 1.2A，再加上板载与 USB 侧的余量， 电脑 USB 口（尤其前置口、无源 HUB）容易在启动瞬间被拉低电压，表现为红灯闪一下又灭、 或串口反复掉线重连。用独立 5V/2A 供电即可稳定。
注意：DC-005 与 USB 同时接入时以板上电源设计为准，若发现异常，只保留一路供电再试。
