EDK60 固件一键烧录

不需要安装任何软件。用 Chrome 或 Edge 浏览器打开本页，插上 USB 线，点按钮即可。

开始前，确认三件事

✅检查项怎么确认
1雷达模组已插在板子的 H3 排针上模组插紧，不要插在 H4
2USB 线已连到电脑板上有绿灯亮
3用的是 Chrome / EdgeFirefox、Safari 不支持，会看不到按钮

烧录（三步）

  1. 点下面的按钮，浏览器会弹出一个列表
  2. 在列表里选带 USB / JTAG / COM 字样的那一项，点「连接」
  3. 点 安装 / Install，等进度条走完（约 10~20 秒），看到「完成」就好了
当前浏览器不支持。请改用电脑上的 Chrome 或 Edge 打开本页。 本页需要用 https:// 或 localhost 打开才能使用串口功能。

如果按钮点了没反应，见下面「常见问题」第 1 条。

烧完之后

  1. 拔掉 USB 线，等 2 秒，再插回去（让板子重新启动）
  2. 看板子上的 丝印 RADAR 的红灯：亮了 = 雷达已上电，正常
  3. 打开串口工具（或我们的上位机页面），选那个 USB 串行设备，波特率随便填 115200
  4. 人坐到雷达正前方 30~150 cm 内，保持不动 20~40 秒，就能看到心率和呼吸率
正常输出长这样：
距离=43cm 体动=4 心率=75bpm 呼吸率=21bpm
刚开始几十秒数据是 0 属于正常——雷达需要一点时间锁定你的呼吸和心跳。

常见问题

1. 点按钮后，列表里找不到设备 / 空白的怎么办？
→ 换一根 能传数据 的 USB 线（很多充电线只有电、没有数据）
→ 换一个 USB 口，优先插电脑机箱后面的口
→ 拔掉 USB，按住板子上的 BOOT 键不放，再插上 USB，然后松开 BOOT，再点按钮
2. 提示「连接失败」或进度条卡住？
→ 先拔掉 USB 再插回，重新点按钮
→ 关掉可能占用串口的软件（串口助手、Arduino IDE、另一个浏览器标签页）
3. 烧成功了，但串口里看不到数据？
→ 看红灯（丝印 RADAR）是否亮：不亮说明模组没插好或插错排针（要插 H3）
→ 别人和雷达之间要有 30~150cm，坐下别乱动，等够 40 秒
→ 确认选的是那个 USB 串行设备，不是别的 COM 口
