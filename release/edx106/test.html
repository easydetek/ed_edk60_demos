连接参数

固定 8 数据位 / 1 停止位 / 无校验 / 无流控。设备走原生 USB CDC， 波特率只影响 Web Serial 的建链参数，不影响实际速率 —— 保持 115200 即可。 本页默认只读：不点按钮不会发出任何字节。

参数配置 未读取

SET 不落 NVS：改完只在本次运行有效，复位 / 重新上电会回到固件默认 （常规 · thr=70 · delay=2000 · lockout=2000 · LED 跟随）。

增益：0x60 的 bit7:4，3 dB/step，n 越小增益越大（距离不够先往小调，误触发变多再往大调）。 窗口：len=窗口长度（0x0d，与存在性探针同寄存器，改过后启动日志会出现 id reg0x0d=… (mismatch) 属正常）；total=观察窗口数（0x30）； cnt=需超阈值的窗口数（0x31，默认 3，降到 2 更易触发但抗噪变差）。

点「下发配置」会先弹出逐条命令清单，确认后才逐条发送，并逐条等回执 （set <key>=… ok rd=，单条超时 800 ms 即中止并列出失败项）。

LED 测试 —

LED on/off 回执是实测读回电平：led on gpio=15 level=1。 LED blink 亮灭 3 次 × 200 ms（约 1.2 s，回执 led blink done）。 LED? 是只读（免确认），给出 level/on/active_level/cfg_enable/trigger_led/follow_out。

重新初始化

RESET 会让设备重跑整套启动序列：软复位 → 写全配置 → 回读校验 → 自检窗口（≈3000 ms）→ 重新挂中断。期间会重新打印启动横幅，自检期内 OUT 恒高， 页面会把它标成灰段。
